# Command Line To-Do List

A simple Command Line To-Do List application built using Python.

This project allows users to manage their daily tasks directly from the terminal. Tasks are stored in a text file so that data is not lost when the program is closed.

---

## Features

- Add a new task
- View all tasks
- Mark a task as completed
- Delete a task
- Tasks are saved permanently in a file (`todo.txt`)

---

## Technologies Used

- Python 3
- File Handling
- Functions / Object Oriented Programming
- Exception Handling

---

## How to Run

1. Make sure Python is installed on your system.
2. Download or clone this project.
3. Open the terminal in the project folder.
4. Run the following command:

python todo.py
